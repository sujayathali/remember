# Claude Plugins by Sujayath & Shayan

A small collection of plugins for Claude Cowork and Claude Code, focused on personal knowledge management and individual productivity.

## How to install

See the [Remember plugin README](plugins/remember/README.md) for install instructions. After install, type **Remember** at the end of any Claude Cowork conversation.

## Plugins in this marketplace

| Plugin | Description | Version |
|---|---|---|
| **[remember](plugins/remember/)** | Turn Claude conversations into structured markdown notes. Ingest existing documents (MD, TXT, PDF, DOCX, PPTX) — incremental by default. Zero infra, pure files, your data stays on your machine. | 2.0.2 |

## Privacy & data

- **Everything stays local.** Files are created in folders you choose. The plugins make zero network calls beyond Claude's normal conversation traffic.
- **No telemetry.** The plugins don't phone home.
- **No accounts.** No signup. No login. No vendor lock-in.
- **Open source.** MIT licensed.
